# 🎓 EduNest — Everything Students Need, In One Place

**Study smarter. Learn faster. Grow better.**

## 💡 About the Project
EduNest is a student-focused learning platform concept designed to bring academic resources and study tools together in one place.

## ❗ Problem Statement
Students often use multiple platforms for study materials, doubt clarification, quizzes, schedules, and career guidance. Managing these separately can make learning less organized.

## 🚀 Proposed Solution
EduNest aims to provide a unified learning experience with AI-assisted study support, learning resources, quizzes, and personalized study planning.

## ✨ Key Features
- 🤖 AI-powered study assistance
- 📚 Study materials and learning resources
- 📝 Quizzes and result tracking
- 📅 Personalized study planner
- 👤 Student profile and progress management
- 💼 Career guidance and learning support

## 🛠️ Technology Areas
- Frontend: React
- Backend: Node.js and Express
- Database: MongoDB
- AI integration: AI-assisted learning support

## 🎯 Objectives
- Make learning resources easier to access.
- Encourage consistent study habits.
- Support interactive learning.
- Help students prepare for academic and career goals.

## 📌 Project Status
Currently under development as a student project.
